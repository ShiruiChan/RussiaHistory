# История России - сайт-презентация

Образовательный сайт из трёх страниц, собранный на **Vite + React**.

- **Главная** - лента ключевых событий истории России.
- **Учёные** - выдающиеся российские учёные.
- **Города** - великие города страны.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Сборка

```bash
npm run build      # собирает в папку dist/
npm run preview    # локальный просмотр собранной версии
```

## Деплой на Vercel

1. Запушьте репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) → **Add New → Project** → выберите репозиторий.
3. Vercel сам определит Vite. Настройки по умолчанию:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. Нажмите **Deploy**.

Файл `vercel.json` уже настроен для корректной работы клиентского роутинга
(`react-router`) - все маршруты ведут на `index.html`.
